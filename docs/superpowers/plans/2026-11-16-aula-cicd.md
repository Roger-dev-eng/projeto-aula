# CI/CD na aula — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Todo push no `main` de `Izaiasjun1Dev/santo-projeto` roda CI e, com a infra da aula de pé, faz deploy no EKS via OIDC; sem infra, o CD é pulado e o pipeline fica verde.

**Architecture:** Módulo Terraform `cicd` (provedor OIDC do GitHub, papel IAM, EKS access entry) chamado da raiz; `preparar.sh`/`destruir.sh` ligam e desligam o segredo `AWS_PAPEL_CICD` com o `gh`; um workflow `.github/workflows/pipeline.yml` com jobs `ci` e `cd`.

**Tech Stack:** Terraform (aws ~> 6.0, lock 6.73.0), GitHub Actions (`actions/*`, `aws-actions/*`), bash 3.2, `gh` 2.104.

**Spec:** `docs/superpowers/specs/2026-11-16-aula-cicd-design.md` (complementa `docs/superpowers/specs/2026-11-16-aula-infra-design.md`).

## Global Constraints

- Repositório público: nenhum ID de conta AWS (12 dígitos) em arquivo versionado; nos logs do Actions o ID aparece mascarado (`mask-aws-account-id: true`).
- Nada de chave de acesso AWS de longa duração; só OIDC.
- Confiança do papel: `repo:Izaiasjun1Dev/santo-projeto:ref:refs/heads/main`, `aud = sts.amazonaws.com` (corrigido no ensaio: sub imutável, variável sub_github).
- Nome do segredo: `AWS_PAPEL_CICD`. Variável raiz: `repositorio_github = "Izaiasjun1Dev/santo-projeto"`. Saída raiz: `papel_cicd`. Saída do módulo: `arn_papel`.
- Acesso ao cluster: `AmazonEKSEditPolicy`, escopo namespace `default`.
- Tag da imagem no ECR: 7 primeiros caracteres do commit. Build `linux/amd64`.
- Sem infra (segredo ausente): CD imprime "Infra desligada: deploy pulado" e termina verde.
- Workflow: um arquivo, jobs `ci` e `cd`, nomes de passos em português, só ações `actions/*` e `aws-actions/*`, versões fixadas por tag maior.
- `main` termina a aula e o ensaio na v1 (`versao 1`). `deployment.yaml` versionado sempre com `URL-DO-REPOSITORIO:v1`.
- Scripts bash 3.2/macOS; legíveis para iniciantes. Infra na AWS nunca sem acompanhamento (regra dos 30 min).
- O exercício "siga a variável" (`repositorios`) continua intacto.

## Review Focus

1. Push no `main` com a infra destruída → job `cd` verde com "Infra desligada: deploy pulado" (Task 2 passo 2 confere a lógica; Task 6 confere de verdade).
2. `gh` sem login ou `gh secret set` falhando no `preparar.sh` → aviso com o comando manual, e o script segue (Task 3 passo 2).
3. `destruir.sh` com tudo já destruído e segredo inexistente → `saida=0` e "nada sobrando" (Task 3 passo 4).
4. ID da conta nos logs públicos do Actions → mascarado (Task 6 passo 5).
5. Pipeline rodando antes de existir o deployment `back` no cluster → `kubectl apply` cria tudo (Task 2 usa `apply`; Task 6 passo 3 confere).

### Task 3: Scripts ligam e desligam o CD

**Files:**
- Modify: `scripts/preparar.sh`, `scripts/destruir.sh`, `scripts/conferir.sh`

**Interfaces:**
- Consome: saída `papel_cicd` e variável `repositorio_github` (Task 1); segredo `AWS_PAPEL_CICD`.
- Produz: segredo gravado após o `apply`; apagado antes do `destroy`; `conferir.sh` acusa papel `santo-projeto-github` e provedor OIDC `token.actions.githubusercontent.com` com tag `Projeto=santo-projeto`.

- [ ] **Passo 1:** `preparar.sh`: `gh` na lista de ferramentas e `gh auth status` na checagem inicial; depois do `apply`, `gh secret set AWS_PAPEL_CICD --repo "$REPO_GITHUB" --body "$($TF output -raw papel_cicd)"` (repo lido do `envs/aula.tfvars`), sem imprimir o ARN; se falhar, aviso com o comando manual e segue. Resumo final diz "CD ligado" ou "CD desligado (segredo não gravado)".
- [ ] **Passo 2:** testar o caminho de falha sem AWS: extrair a linha do `gh secret set` com `--repo Izaiasjun1Dev/repo-que-nao-existe` e conferir que o bloco de aviso roda e não sai com erro (descrever o teste no relatório; não rodar o `preparar.sh` inteiro).
- [ ] **Passo 3:** `destruir.sh`: antes do `terraform destroy`, `gh secret delete AWS_PAPEL_CICD --repo "$REPO_GITHUB"`; falha só avisa. `conferir.sh`: novas checagens IAM (globais) do papel e do provedor OIDC com a tag do projeto, no mesmo padrão `chamar`/`processar` (falha de checagem → exit 2).
- [ ] **Passo 4:** `bash -n scripts/*.sh`; com a infra destruída, `scripts/conferir.sh; echo saida=$?` → `nada sobrando`, `saida=0`; `scripts/destruir.sh; echo saida=$?` → aviso de segredo inexistente, destroy sem mudanças, `saida=0`.
- [ ] **Passo 5:** commit `feat(scripts): preparar e destruir ligam o CD; conferir vê o IAM do projeto`.
